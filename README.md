# Маршруты уборки дворов САО Москвы

Открыть карту: https://andreikulidzhanov6-del.github.io/marshruty-sao/

Интерактивная карта: 71 участок, 16 районов. Рабочий и холостой ход, протяжённость по фильтрам, выбор нескольких районов, направление движения, начало и конец участка, поиск улиц, схема / спутник / гибрид, панорамы Яндекса с мини-картой.

Сайт — статические HTML и JavaScript. Сборка и сервер не требуются. GitHub Pages публикует корень ветки `main`; последующие изменения в этой ветке обновляют сайт по тому же адресу.

## Файлы

- `index.html` — карта, данные маршрутов, стили, поиск и мобильная версия.
- `panorama.html` — окно панорамы.
- `panorama-map.js` — панорама, мини-карта и фактическая точка съёмки.
- `map-config.js` — настройки браузерного JavaScript API Яндекса.
- `.nojekyll` — публикация без Jekyll.

Для работы API Яндекса на новом домене добавьте `andreikulidzhanov6-del.github.io` к разрешённым HTTP Referer в кабинете API Яндекса. Старый домен оставьте разрешённым. Не отключайте ограничения ключа целиком.
